================================================================================
  📊 WHAT GETS MEASURED
================================================================================

Complete end-to-end model swap time including:
  ✅ Weight loading (disk → GPU or storage → GPU)
  ✅ vLLM engine initialization
  ✅ Memory allocation
  ✅ CUDA graph compilation
  ✅ Model warmup
  ✅ First inference token

This is TOTAL time from "start loading" to "ready for inference".

  💡 KEY ADVANTAGES

FlashTensors Warm Swaps:

Default Models (for demo speed):

Default Swap Sequence:
  1. Load Model A (first load)
  2. Load Model B (first load + warm swap)
  3. Load Model A (warm swap)
  4. Load Model B (warm swap)
  5. Load Model A (warm swap)

Average calculated from warm swaps #2-5.
